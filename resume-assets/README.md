# resume-assets

Files `resume.tex` needs beside it when it compiles.

- `RobotoMono-Bold.ttf` — the green inline-code face (`\code{...}`). Roboto Mono,
  Copyright 2015 The Roboto Mono Project Authors, Apache License 2.0.
  Source: https://github.com/googlefonts/RobotoMono

`resume.tex` falls back to an installed Roboto Mono, then to TeX Gyre Cursor,
if this file is missing. When opening the resume in Overleaf, upload this
folder with it and set the compiler to XeLaTeX.
